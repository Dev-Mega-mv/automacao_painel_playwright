Credenciais Infox
O que coletar
O robô procura a linha dessa origem em Código Estabelecimento. Vale para todos os credenciados.
Para cada credenciado:
  • em Opções > Cadastro > Código Estabelecimento, lê a linha da origem: código, data de cadastro, data de alteração e situação;
  • se o código estiver INATIVO, não abre os contratos;
  • senão, abre cada contrato e agrupa os números pela situação do arquivo dessa rede na tabela "Rede de captura" (vazia = DESATIVADO).

Como montar a planilha
  • Uma coluna COD com um credenciado por linha (também vale CODIGO, CNPJ, CPF, COD_CNPJ ou CPF_CNPJ). Exemplo: 12345.
  • O tipo de pesquisa e a origem escolhidos acima valem para todas as linhas.
  • Outras colunas, como FANTASIA, são ignoradas. Linhas sem código são puladas.
  • O relatório é salvo a cada credenciado, então o que já foi coletado não se perde se o portal cair.
